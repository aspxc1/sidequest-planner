## Product Purpose
Choose an idea, define a manageable scope, turn it into milestones and tasks, compare architectures, track work, record technical decisions, and retain reusable engineering notes.

Roadmap, task board, architecture comparison, API/data notes, deployment checklist, decisions and reusable notes. Software components and GPT/API components must be visibly distinguished. Browser-local records with JSON backup/restore. No API keys, accounts or external calls required. Browser storage is specific to the browser and app origin; export is the portable backup.
